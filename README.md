# CINEMA — каталог фильмов и сериалов

**Русскоязычный интерфейс для каталога и просмотра видео.** Проект основан на открытом коде NebulaPlay; название, оформление и текст интерфейса адаптированы для CINEMA.

## Возможности

- Просмотр каталога, поиск по названиям и фильтрация по жанру, стране и году.
- Страницы с информацией о фильме, списками серий и рекомендациями.
- Видеоплеер с выбором качества, регулировкой скорости, полноэкранным режимом и запоминанием позиции.
- История просмотров, избранное и личный список сохраняются в браузере.
- Подключение пользовательских каталогов и видеоисточников через настройки.
- Русские подписи интерфейса и переводы распространённых жанров, стран и статусов сериала.

## Важно о каталоге

Встроенные непроверенные источники по умолчанию отключены. После первого запуска каталог может быть пустым: откройте меню источников и добавьте API каталога или прямую ссылку на видео, которыми разрешено пользоваться.

Названия фильмов, имена актёров и описания показываются так, как их передаёт выбранный источник. Интерфейс переводится на русский, но это не означает автоматический перевод всех пользовательских или сторонних текстов.

Используйте только собственные материалы, видео с разрешением правообладателя или произведения, находящиеся в общественном достоянии. Наличие ссылки в стороннем источнике само по себе не подтверждает право на просмотр или распространение.

## Статус проекта

Проект находится в разработке. Перед публикацией проверьте подключение источника, сборку интерфейса и воспроизведение разрешённого тестового видео.

## Технологии

- React и TypeScript
- Vite
- Tailwind CSS
- Video.js
- Node.js-прокси для поддерживаемых запросов к внешним каталогам

## Запуск на компьютере

Требуются Node.js и пакетный менеджер pnpm.

```bash
pnpm install
pnpm dev
```

Откройте адрес, который покажет Vite в терминале.

Проверка типов и сборка:

```bash
pnpm typecheck
pnpm build
```

Тесты:

```bash
pnpm test
```

Команда `pnpm build` собирает интерфейс и отдельно компилирует Node.js-прокси. Обычная статическая публикация Vite на Vercel не запускает этот прокси автоматически: если выбранный источник требует прокси, серверную часть нужно разместить отдельно и настроить адреса запросов.

## Подключение источника

В интерфейсе откройте меню источников и выберите добавление источника. В зависимости от возможностей источника можно указать:

- адрес JSON-каталога;
- совместимый адрес CMS API;
- прямую ссылку на видео в формате MP4, WebM или M3U8;
- JSON с описанием собственного каталога.

Некоторые внешние API могут быть недоступны из браузера из-за ограничений CORS, особенностей авторизации или требований самого сервиса. Не добавляйте закрытые протоколы и источники, использовать которые у вас нет права.

## Данные и конфиденциальность

Настройки источников, список фильмов и история просмотра хранятся локально в текущем браузере. Они не синхронизируются между устройствами и могут быть удалены при очистке данных браузера. Внешние источники могут получать сетевые запросы при просмотре каталога или видео — ознакомьтесь с их условиями и политикой конфиденциальности.

## Публикация

Для публикации фронтенда импортируйте репозиторий в Vercel, выберите ветку `dev` и выполните стандартную сборку Vite. Команда сборки в проекте — `pnpm build`, выходная папка интерфейса — `dist`. После публикации проверьте главную страницу, поиск, настройки источников и воспроизведение разрешённого тестового видео.
